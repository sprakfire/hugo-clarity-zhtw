Hugo 是以 Go 語言撰寫的開源靜態網站產生器，採用 [Apache 2.0 授權條款](https://github.com/gohugoio/hugo/blob/master/LICENSE) 發布。Hugo 支援 TOML、YAML 與 JSON 資料檔案格式、Markdown 與 HTML 內容檔案，並透過短代碼（shortcode）加入豐富內容。其他值得一提的功能還包括分類法（taxonomies）、多語言模式、圖片處理、自訂輸出格式、HTML／CSS／JS 壓縮，以及對 Sass SCSS 工作流程的支援。

Hugo 使用了多項開源專案，包括：

* https://github.com/yuin/goldmark
* https://github.com/alecthomas/chroma
* https://github.com/muesli/smartcrop
* https://github.com/spf13/cobra
* https://github.com/spf13/viper

Hugo 非常適合用來架設部落格、公司官網、作品集網站、線上雜誌、單頁應用程式，甚至是擁有上千頁面的大型網站。

Hugo 適合那些想要親手撰寫網站、卻不想煩惱複雜執行環境、相依套件與資料庫設定的人。

以 Hugo 建置的網站速度極快、安全性高，且可以部署到任何地方，包括 AWS、GitHub Pages、Heroku、Netlify 以及其他任何主機服務商。

歡迎前往 [GitHub](https://github.com/gohugoio) 深入了解並參與貢獻。
